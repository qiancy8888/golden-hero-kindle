# 黄金版核对清单

资料以用户提供的 NC1020 黄金版 Flash 为主。其他版本和重制版用于找线索，规则和地图按来源分别记录。

| 内容 | 已核对 | v0.2.0 与原版的差异或待验收项 |
| --- | --- | --- |
| 开局 | 原版离线运行到序章、选角、姓名与密码、四项 20 点的初始属性及入镇 | 当前从预设姓名选角。原版输入、序章演出和原版出生点画面待还原 |
| 世界 | Flash 第 `0C` 页 `0x6391` 起可读到平安镇、八个门派所在区域、铸剑谷、阎罗府、桃花源及八个暗黑据点名称 | 当前为 28 张可通行的重绘场景，出口、室内地图和完整 NPC 表待逐图核对 |
| 搬石料 | Flash 第 `0D` 页含接任务、交付、经验和潜能结算；结算代码包含除以 1500 的参数、加 40 和潜能减半 | 当前使用 1000 经验门槛和推定奖励算法；可重复时机、上限和零钱待实测 |
| 战斗 | 黄金版资料记载回合攻击、绝招及门派武学；八坛相关名称存在于 Flash | 命中、内力、招式、伤害、门派条件与装备数值使用当前平衡配置，待逐项测定 |
| 主线 | 村长授第一张地图，逐坛取得下一个据点情报并对抗总瓢把子 | 当前已有八场可完成的战斗与结局。发放门槛、地图路径、坛主招式、原版结局文本和分支待验证 |
| 其余玩法 | 黄金版资料可定位官府除恶、桃花源、钓鱼、铸剑和更多支线 | 当前已有基础除恶、钓鱼、采矿铸剑、置办家园、阎罗府归来。其余物品、隐藏支线、家园配置和武林大会待实现 |
| 实机 | 用户确认 v0.1.0 可玩 | v0.2.0 须验证长时间运行、休眠唤醒、退出恢复和再次启动读档 |

参考 [NC1020 黄金版任务反汇编笔记](https://happysoul.github.io/nes/6502/page/jiben/modify_gmud.htm) 和 [黄金版机制与剧情资料](https://bkso.baidu.com/item/%E9%BB%84%E9%87%91%E8%8B%B1%E9%9B%84%E5%9D%9B%E8%AF%B4/9739623)。
