# 黄金版核对清单

资料以用户提供的 NC1020 黄金版 Flash 为主。其他版本和重制版用于找线索，规则和地图按来源分别记录。

| 内容 | 已核对 | v0.2.0 与原版的差异或待验收项 |
| --- | --- | --- |
| 开局 | 原版离线运行到序章、选角及入镇。初始 14 岁、四项先天属性各 20、气血 100、内力 0、经验 0、潜能 100、金钱 100，食物 100/375、饮水 100/360 | 当前复用已核对的默认属性和资源。预设姓名、序章演出、出生点画面以及成长后的属性公式仍需核对 |
| 世界 | Flash 第 `0C` 页 `0x6391` 起可读到区域名称。运行时 `0x47/0x48` 指示场景和区域，`0x49/0x4A` 指向按三字节条目排列的地图对象列表，`0xFF` 结束。静态索引含 98 个槽，其中 91 个有对象记录 | 当前为 28 张可通行的重绘场景。原版场景的实际可达性、动态出口和 NPC 身份待逐图核对 |
| 搬石料 | Flash 第 `0D` 页含接任务、交付、经验和潜能结算；结算代码包含除以 1500 的参数、加 40 和潜能减半 | 当前使用 1000 经验门槛和推定奖励算法；可重复时机、上限和零钱待实测 |
| 战斗 | 从 Flash 第 `0C` 页读取 54 项武学名和 89 项道具名 | 54 项武学可按门派及基础功训练。命中、内力、绝招效果、伤害、门派条件及道具数值待逐项核对 |
| 主线 | 村长授第一张地图，逐坛取得下一个据点情报并对抗总瓢把子。根据原版场景中的路牌核对了八坛所属区域 | 当前已有八场可完成的战斗与结局。发放门槛、各区域内具体路线、坛主招式、原版结局文本和分支待验证 |
| 其余玩法 | 黄金版资料可定位官府除恶、桃花源、钓鱼、铸剑和更多支线 | 当前已有基础除恶、钓鱼、采矿铸剑、置办家园、阎罗府归来。其余物品、隐藏支线、家园配置和武林大会待实现 |
| 实机 | 用户确认 v0.1.0 可玩 | v0.2.0 须验证长时间运行、休眠唤醒、退出恢复和再次启动读档 |

参考 [NC1020 黄金版任务反汇编笔记](https://happysoul.github.io/nes/6502/page/jiben/modify_gmud.htm) 和 [黄金版机制与剧情资料](https://bkso.baidu.com/item/%E9%BB%84%E9%87%91%E8%8B%B1%E9%9B%84%E5%9D%9B%E8%AF%B4/9739623)。

可用 `python scripts/analyze-nc1020-atlas.py D:/kindle/nc1020.fls` 重现索引和名称统计。指定 `--private-output` 可在本地导出记录供核对。
