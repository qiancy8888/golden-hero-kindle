This folder contains documentation only; game images do NOT belong in
/mnt/us/golden_hero/roms.

On Kindle, the KUAL launcher reads user-provided images from:
  /mnt/us/documents/GoldenHeroPrivate/roms/obj_lu.bin
  /mnt/us/documents/GoldenHeroPrivate/roms/nc1020.fls

Expected exact sizes:
  obj_lu.bin   25,165,824 bytes (24 MiB)
  nc1020.fls    1,048,576 bytes (1 MiB)

No game ROM or firmware image is included, downloaded, or bundled by this
project. The upstream emulator source-code license does not automatically
license these binary images. Only use images you are legally entitled to use.
See PRIVATE-ROM-SETUP.md for the private local data layout.
